# 🎮 RPS Tank Battle (가위바위보 탱크 대전)

추억의 탱크 대전 게임에 가위바위보 시스템을 결합한 새로운 2인 대전 게임!

![Game Genre](https://img.shields.io/badge/Genre-Action%20%2B%20Strategy-brightgreen)
![Players](https://img.shields.io/badge/Players-2-blue)
![Platform](https://img.shields.io/badge/Platform-Web-orange)

## 🕹️ 게임 소개

RPS Tank Battle은 클래식한 탱크 대전 게임과 가위바위보를 결합한 독특한 게임입니다. 플레이어는 탱크를 조종하여 상대와 충돌하고, 충돌 시 가위바위보로 전투를 벌입니다!

### 게임의 특징
- 🎯 **2인 대전**: 친구와 함께 즐기는 로컬 멀티플레이어
- ⚔️ **전략적 전투**: 단순한 가위바위보가 아닌, 각 선택마다 다른 데미지
- 🎨 **레트로 감성**: 추억의 탱크 게임 느낌을 살린 디자인
- 💥 **실시간 액션**: 빠른 반응과 전략이 필요한 게임플레이

## 🎲 게임 규칙

### 기본 조작
- **플레이어 1 (파란 탱크)**
  - W: 위로 이동
  - S: 아래로 이동
  - A: 왼쪽으로 이동
  - D: 오른쪽으로 이동

- **플레이어 2 (빨간 탱크)**
  - ↑: 위로 이동
  - ↓: 아래로 이동
  - ←: 왼쪽으로 이동
  - →: 오른쪽으로 이동

### 전투 시스템

탱크가 충돌하면 가위바위보 대결이 시작됩니다!

| 선택 | 효과 | 데미지 |
|------|------|--------|
| ✊ **바위** | 강한 공격 | 30 |
| ✋ **보** | 방어막 (약한 공격) | 10 |
| ✌️ **가위** | 빠른 공격 | 20 |

- **승리**: 상대에게 선택한 무기의 데미지를 입힙니다
- **패배**: 데미지를 받지 않습니다
- **무승부**: 양쪽 모두 10 데미지를 받습니다

### 승리 조건
상대 플레이어의 체력을 0으로 만들면 승리!

## 🚀 실행 방법

### 1. 파일 다운로드
이 저장소를 클론하거나 다운로드합니다.

```bash
git clone <repository-url>
cd retro_games
```

### 2. 게임 시작
`index.html` 파일을 웹 브라우저로 엽니다.

```bash
# 간단한 방법
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux
```

또는 로컬 서버를 사용할 수 있습니다:

```bash
# Python 3
python -m http.server 8000

# Node.js (http-server 설치 필요)
npx http-server
```

그 후 브라우저에서 `http://localhost:8000`으로 접속합니다.

## 🎯 게임 플레이 팁

1. **위치 선정이 중요합니다**: 벽 근처에서 싸우면 도망갈 공간이 없습니다
2. **패턴 읽기**: 상대방의 선택 패턴을 파악하세요
3. **바위는 강력하지만**: 보에 약하다는 것을 잊지 마세요
4. **무승부 조심**: 양쪽 다 피해를 입으니 신중하게 선택하세요
5. **쿨다운 활용**: 전투 후 2초 쿨다운을 이용해 위치를 재조정하세요
